# 功能：目录树侧边栏（二期追加）

## 背景

多文件支持（feature-multi-file）完成后，文件切换器是一个扁平下拉框。当文件数量增多（10+）时，快速定位目标文件变得困难。每个文件已具备 `docPath` 字段（如 `docs/rules.md`、`docs/api.md`），其中天然包含目录层级信息。本功能将 docPath 中的 `/` 前缀推导为目录树视图，提供类似 VS Code 资源管理器的左侧抽屉栏，方便用户按目录分组浏览、折叠、快速切换。

## 需求

### R1 侧边栏抽屉
- R1: 顶部工具栏最左侧新增一个 **☰ 图标按钮**（3 条横线的汉堡菜单，或 GitHub 风格的 `<>`）；点击后切换左抽屉显示/隐藏
- R2: 左抽屉宽度固定 **220px**，初始隐藏（transform: translateX(-100%)），展开时用 300ms transform 动画滑入
- R3: 抽屉展开时，Monaco 左栏被推挤而非叠加在上方（flex 布局自然重排）
- R4: 当前文件切换后，抽屉自动保持展开状态直到用户手动收起

### R2 目录树渲染（方案 A：纯 UI 推导）
- R5: 目录树**不新增数据模型**，直接从 `state.files` 的 `docPath` 推导：
  - 按 `/` 分割 docPath，除最后一段外视为目录层级
  - 示例：`docs/rules.md` → 目录节点 `docs/` 下挂文件 `rules.md`；`README.md` → 根目录直接挂文件
- R6: 目录节点显示为 **📂** 图标 + 目录名（带尾部 `/`），文件节点显示为 **📄** + 文件名（`name` 字段优先，没填则取 docPath 最后一段）
- R7: 根目录文件直接显示在顶层，不额外创建"根目录"节点
- R8: 多级目录支持：`docs/archive/old/rules.md` → 三级嵌套目录，每级缩进 16px

### R3 目录展开/折叠 + 文件点击
- R9: 点击目录节点（📂 区域）→ 切换其子级显示/隐藏状态；目录图标在展开时变 **📂**、折叠时变 **📁**
- R10: 目录折叠状态持久化到 localStorage，key 为 `doc-branch-folder-collapsed-v1`，值为 `['docs/', 'docs/archive/']` 数组
- R11: 点击文件节点 → 切换到该文件（调 `Storage.switchToFile(id)`），Monaco 刷新 + 批注树刷新 + 高亮刷新
- R12: 当前激活的文件在目录树中高亮（左侧 3px `#0969da` 竖条 + 背景 `rgba(9,105,218,0.1)`）

### R4 新建/重命名适配
- R13: 新建文件弹窗增加 **"所属目录"** 输入框（默认值 `docs/`，可改），与 docPath 格式联动（实际写入的 docPath = 目录 + 文件名）
- R14: 重命名文件弹窗的 docPath 字段保留原样，改完后目录树自动重新渲染（无额外操作）

### R5 工具栏原有切换器的降级
- R15: 左抽屉展开时，顶部的文件切换下拉框 **保留但标注**（可加个 hint 提示"也可在左侧目录树点击切换"），不移除——兼容习惯用下拉的用户
- R16: 左抽屉收起时，顶部下拉框恢复为主要切换入口

## 验收标准

- [ ] 点击 ☰ 按钮，左抽屉滑入/滑出，Monaco 区域同步被推挤
- [ ] 目录节点按 docPath 正确分组，多级嵌套缩进正确
- [ ] 点击 📁 → 折叠子级；点击 📂 → 展开子级；刷新页面后折叠状态保留
- [ ] 点击文件节点 → Monaco 切换 + 批注树刷新，该文件在树中高亮
- [ ] 新建文件填 `docs/archive/` → 自动挂到三层嵌套目录下
- [ ] 收起抽屉 → 顶部下拉框仍可正常切换文件
- [ ] GitHub Sync 完全不受影响（PUT 路径仍是 docPath）

## 非目标

- **方案 B 显式目录节点**：不创建独立的 `{type:'folder'}` 数据结构，目录完全由 docPath 推导
- 创建空目录：没有文件就没有目录（纯 UI 推导的天然限制）
- 重命名目录：改目录名 = 批量修改所有子文件的 docPath，属于方案 B 范畴，不在本期
- 拖放文件到目录：方案 B 范畴，不在本期
- 右键目录操作菜单：不在本期

## 技术约束

- 目录树递归渲染函数：从 `state.files` 构建嵌套 Map，一次遍历完成，O(N) 复杂度
- 折叠状态 key：`doc-branch-folder-collapsed-v1`，值为被折叠目录的**前缀路径数组**（如 `['docs/', 'docs/archive/']`），方便查找
- 抽屉显隐状态 key：`doc-branch-sidebar-open-v1`（boolean），恢复用户偏好
- 左抽屉和 Monaco 的布局：当前 `#main` 是 flex 横向布局，插入一个 `#sidebar` 子元素即可，flex 自动分配宽度，无需 calc 计算
- 抽屉初始隐藏的实现：默认隐藏（display:none）还是用 transform off-screen？**推荐 display:none**，避免初始渲染时 Monaco 先被挤压再回弹的闪烁
