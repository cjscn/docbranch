# 功能：批注标签系统（二期）

## 背景

一期所有批注都是同一视觉权重，用户无法快速区分哪些是"定义"、哪些是"公式"、哪些是"待确认"。二期为每条批注增加一个可编辑的标签，便于按类型筛选和视觉区分。

## 需求

### R1 预设标签
- R1: 提供 4 种预设标签类型，每种有颜色：
  - **定义**（`definition`）：蓝色 `#0969da`
  - **公式**（`formula`）：紫色 `#8250df`
  - **规则**（`rule`）：绿色 `#1a7f37`
  - **待确认**（`todo`）：橙色 `#bf8700`
- R2: 默认值为「定义」，可留空（无标签）

### R2 标签选择
- R3: 新建批注时（一级/子批注），在输入说明弹窗中增加标签下拉选择（单选 + 可清空）
- R4: 已有批注卡片上显示标签 chip（圆角 pill 样式，实心颜色背景 + 白色文字）
- R5: 点击卡片上的标签 chip 弹出下拉菜单，可修改或清除标签

### R3 数据结构变更
- R6: 在批注节点上新增 `tag: string | null` 字段；一级批注和子批注均支持
- R7: JSON 导入导出时保留 tag 字段；旧版本（无 tag）数据导入时补 null

### R4 右栏筛选
- R8: 右栏顶部搜索框旁增加「标签筛选」下拉，可按标签类型过滤显示的批注（与关键词搜索**叠加生效**）
- R9: 筛选状态**不持久化**（每次刷新恢复全部显示）

### R5 视觉区分
- R10: 带标签的卡片在 `.card` 上追加 `.tag-definition / .tag-formula / .tag-rule / .tag-todo` class，可用于未来卡片左侧边缘色条等视觉强化

## 验收标准

- [ ] 新建批注弹窗中有标签下拉，可选择 4 种预设或留空
- [ ] 卡片上显示对应的彩色标签 chip
- [ ] 点击 chip 可修改标签
- [ ] 右栏筛选按标签过滤正常
- [ ] 旧数据（无 tag 字段）导入不报错，标签显示为空
- [ ] JSON 导出包含 tag 字段

## 非目标

- 自定义标签（颜色由用户自定义）
- 标签多选（一条批注只归属一个类型）
- 标签统计面板（二期后期可考虑）
- 标签与搜索关键词联动高亮

## 技术约束

- tag 字段在 `Annotations.addTopLevel / addChild` 时作为可选参数传入
- JSON 导入时兼容无 tag 字段的旧数据（检查 `if (typeof a.tag !== 'string') a.tag = null`）
- 颜色方案对齐 GitHub 主题风格（与一期白色主题不冲突）
