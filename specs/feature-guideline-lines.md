# 功能：SVG 虚线指引连线（二期）

## 背景

一期实现了左右双栏批注工具，但左栏高亮文本与右栏对应批注卡片之间没有视觉关联。文档批注多时，用户需要来回扫视才能定位"这段原文对应哪张卡片"。二期通过 SVG 悬浮层绘制红色贝塞尔虚线连接两侧，直观展示关联关系。

讨论补充：如果无条件显示所有连线，会出现"页面全是虚线"的视觉噪音（意面问题）。因此采用 **默认按需出现 + 三态开关** 的混合方案，在不牺牲关联能力的前提下保持页面干净。

## 需求

### R1 连线基础能力
- R1: 顶层 SVG 悬浮图层（`pointer-events: none`，不拦截文字选中和鼠标点击），z-index 最高
- R2: 红色贝塞尔虚线，`stroke: #ff6b6b` + `stroke-dasharray: 6 4`，两端圆角（`stroke-linecap: round`）
- R3: 曲线向上拱起 20-30px，起点 = 左栏高亮片段右侧中点（一级批注）或卡片内高亮起点（子批注），终点 = 对应批注卡片左侧中点

### R2 一级批注连线
- R4: **点击 / 聚焦** 左栏高亮文本 → 页面绘制虚线，连接该高亮片段到右栏对应一级批注卡片；右栏自动滚动定位并激活卡片
- R5: 一级批注无子批注时，点击卡片内原文片段区域（sourceText）→ 反向绘制虚线连接回左栏

### R3 子批注连线
- R6: **点击 / 聚焦** 父批注卡片内高亮关键词（子批注的 sourceText 对应的 mark 元素）→ 绘制虚线连接到子批注卡片
- R7: 子批注卡片同样支持反向定位（点击 sourceText → 滚动到父卡片并绘制虚线）

### R4 触发模式与全局开关（v2: 方案 C 混合模式）
- R8: **默认智能模式（hover/聚焦触发）**（v2: 从"单激活模式点击触发"改为 hover/聚焦按需出现）
  - 鼠标**悬停**在右栏某张批注卡片上 → 实时绘制该卡片对应的虚线
  - 鼠标**移开** → 虚线立即消失（hover 场景）
  - **点击**卡片（聚焦）→ 虚线保持，即使鼠标移出（方便查看/交互）
  - **再次点击同一卡片**或按 `Esc` → 取消聚焦，虚线消失
  - **触摸设备退化**：无 hover，退化为"点按卡片 → 虚线保持 → 再次点按 / Esc 取消"，与原点击行为一致
- R9: **三态全局开关**（v2 新增），工具栏 `🔗 虚线指引` 按钮循环切换，默认 = 智能模式
  - **状态 1 · 智能模式**（默认）：hover/聚焦才出现（R8 行为）
  - **状态 2 · 永久显示全部**：一次性绘制当前可见范围内**所有**批注对应的虚线，用于批量审查
  - **状态 3 · 全部关闭**：无论 hover 还是点击都不绘制任何虚线，彻底隐藏 SVG 图层
  - 状态切换时，SVG 图层立即清除并按新状态重绘（或隐藏）
  - 当前状态持久化到 localStorage，key `doc-branch-guideline-mode-v1`（取值 `"smart"` / `"all"` / `"off"`）
- R10: **Shift 多激活**（v2: 限定到"永久显示"模式下生效；原默认行为现已由 R8 hover/聚焦接管）
  - 仅在 R9 状态 2（永久显示全部）下，按住 `Shift` 点击可**累积额外**显示多条虚线（临时叠加）
  - 智能模式（状态 1）下 Shift 点击等价于普通聚焦（只显示当前这一条）
  - 再次点击已激活项可取消；点击空白处或 `Esc` 清除所有临时叠加的虚线
- R11: 切换激活连线时，目标卡片自动滚动到可见区域（hover 场景下也触发，方便用户快速定位）

### R5 重绘触发时机
- R12: 窗口 resize 时全部连线重绘（监听 `window.resize` 或 `ResizeObserver`）
- R13: 右栏展开/折叠子批注时（R26 折叠功能），受影响的连线重绘
- R14: 点击激活后 50ms 内如果有布局变化（Monaco 滚动、右栏滚动、折叠展开），延迟重绘一次（防抖）
- R15: **hover 状态切换时**立即重绘 / 清除对应虚线（v2 新增）；hover 期间如发生滚动，虚线位置实时跟随

## 验收标准

- [ ] 默认状态下，鼠标移动→停留在右栏卡片上，虚线实时出现；鼠标移开，虚线立即消失
- [ ] 点击卡片，虚线保持；再次点击同一卡片或 Esc，虚线消失
- [ ] 点击左栏高亮文本，虚线连接到右栏对应卡片，曲线向上拱起，卡片自动滚动定位
- [ ] 点击卡片内高亮关键词（有子批注时），虚线连接到子批注卡片
- [ ] 工具栏 🔗 按钮三态循环：智能模式（默认）→ 永久显示全部 → 全部关闭
- [ ] 切到"永久显示全部"后，所有可见批注的虚线同时存在；Shift 点击可累积临时叠加
- [ ] 切到"全部关闭"后，无论 hover 还是点击，页面上不出现任何虚线
- [ ] 刷新页面后，开关状态恢复上次的持久化值（智能 / 全部 / 关闭）
- [ ] 窗口 resize 后连线位置正确
- [ ] 子批注折叠/展开后，连线自动重绘
- [ ] Esc 键可清除当前激活的虚线（智能模式 / Shift 多激活模式）

## 非目标

- 连接线带箭头（二期只做虚线）
- 连线带动画效果（流动虚线等）
- 左栏卡片边缘发光等视觉装饰
- 触摸设备专属 UI（触摸退化到点按即可，不做双指手势等）

## 技术约束

- SVG 图层为顶层 `<svg>` 元素，宽高覆盖整个 viewport，`position:fixed; top:0; left:0`
- 坐标转换：
  - **一级批注**：左栏高亮片段位置 = `editor.getDomNode().getBoundingClientRect()` + `editor.getLayoutInfo()` 计算行高、列宽 → 推出片段右侧中点坐标
  - **子批注**：父卡片内高亮关键词位置 = DOM 查询 `mark.guideline-source[data-child-id="xxx"]` → `element.getBoundingClientRect()` → 取起点坐标
  - 右栏卡片位置 = `cardElement.getBoundingClientRect()` 取左侧中点
- 性能：永久显示模式下每帧最多 30 条虚线；智能模式下同时仅 1 条；单帧重绘 < 16ms
- hover 重绘防抖：同一卡片 hover 进入/离开在 16ms 内只触发一次重绘，避免闪烁
- localStorage key：`doc-branch-guideline-mode-v1`，默认值 `"smart"`
