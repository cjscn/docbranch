# 功能：SVG 虚线指引连线（二期）

## 背景

一期实现了左右双栏批注工具，但左栏高亮文本与右栏对应批注卡片之间没有视觉关联。文档批注多时，用户需要来回扫视才能定位"这段原文对应哪张卡片"。二期通过 SVG 悬浮层绘制红色贝塞尔虚线连接两侧，直观展示关联关系。

## 需求

### R1 连线基础能力
- R1: 顶层 SVG 悬浮图层（`pointer-events: none`，不拦截文字选中和鼠标点击），z-index 最高
- R2: 红色贝塞尔虚线，`stroke: #ff6b6b` + `stroke-dasharray: 6 4`，两端圆角（`stroke-linecap: round`）
- R3: 曲线向上拱起 20-30px，起点 = 左栏高亮片段右侧中点（一级批注）或卡片内高亮起点（子批注），终点 = 对应批注卡片左侧中点

### R2 一级批注连线
- R4: 点击左栏高亮文本 → 页面绘制虚线，连接该高亮片段到右栏对应一级批注卡片；右栏自动滚动定位并激活卡片
- R5: 一级批注无子批注时，点击卡片内原文片段区域（sourceText）→ 反向绘制虚线连接回左栏

### R3 子批注连线
- R6: 点击父批注卡片内高亮关键词（子批注的 sourceText 对应的 mark 元素）→ 绘制虚线连接到子批注卡片
- R7: 子批注卡片同样支持反向定位（点击 sourceText → 滚动到父卡片并绘制虚线）

### R4 多条共存与切换
- R8: **单激活模式**（二期早期）：每次只显示当前激活的一条虚线；新的点击替换旧的连线
- R9: **多激活模式**（二期增强）：按住 `Shift` 点击可累积显示多条虚线；再次点击已激活项可取消；点击空白处清除全部
- R10: 切换激活连线时，目标卡片自动滚动到可见区域

### R5 重绘触发时机
- R11: 窗口 resize 时全部连线重绘（监听 `window.resize` 或 `ResizeObserver`）
- R12: 右栏展开/折叠子批注时（R26 折叠功能），受影响的连线重绘
- R13: 点击激活后 50ms 内如果有布局变化（Monaco 滚动等），延迟重绘一次（防抖）

## 验收标准

- [ ] 点击左栏高亮文本，红色贝塞尔虚线连接到右栏对应卡片，曲线向上拱起
- [ ] 点击卡片内高亮关键词（有子批注时），虚线连接到子批注卡片
- [ ] 点击空白处或 Esc，连线消失
- [ ] 按住 Shift 点击两条不同高亮文本，两条虚线同时显示
- [ ] 窗口 resize 后连线位置正确
- [ ] 子批注折叠/展开后，连线自动重绘

## 非目标

- 连接线带箭头（二期只做虚线）
- 连线带动画效果（流动虚线等）
- 左栏卡片边缘发光等视觉装饰

## 技术约束

- SVG 图层为顶层 `<svg>` 元素，宽高覆盖整个 viewport，`position:fixed; top:0; left:0`
- 坐标转换：左栏 Monaco 文本位置需 `editor.getDomNode().getBoundingClientRect()` + `editor.getLayoutInfo()` 计算；右栏卡片位置用 `element.getBoundingClientRect()`
- 性能：每帧最多 10 条虚线同时存在，重绘 < 16ms
